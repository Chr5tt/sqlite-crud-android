SQLite CRUD (Room) - Tugas Chapter 7

Cara menjalankan:
1. Ekstrak zip.
2. Android Studio > File > Open > pilih folder SqlLiteCrud.
3. Tunggu Gradle Sync selesai (butuh internet untuk mengunduh dependency).
   Jika Android Studio meminta versi Gradle atau JDK, pilih Gradle 8.0 dan JDK 17 (Embedded JDK).
4. Pilih emulator atau HP, tekan Run.

Fitur CRUD:
- Create : isi form, tekan Simpan.
- Read   : daftar mahasiswa tampil di bawah form.
- Update : ketuk item, ubah data, tekan Update. Batal Edit membatalkan.
- Delete : ketuk ikon tempat sampah, lalu Hapus.
